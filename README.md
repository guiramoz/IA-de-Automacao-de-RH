# IA-de-Automa-o-de-RH
Projeto desenvolvido no curso de Inteligências Artificiais Generativas Aplicada ao ChatGPT do SENAI. Utiliza API da OpenAI, Hugging Face, MCP e Google Cloud para criar IA de apoio ao setor de Recursos Humanos, capaz de interpretar solicitações, agendar entrevistas, criar reuniões no Google Meet, enviar e-mails e atualizar planilhas automaticamente.
