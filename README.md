# Assistente de RH com Inteligência Artificial e MCP

## 📖 Sobre o Projeto

Este projeto foi desenvolvido durante o curso de **Inteligências Artificiais Generativas Aplicada ao ChatGPT** do SENAI. O objetivo é criar um assistente inteligente para o setor de Recursos Humanos, utilizando Inteligência Artificial Generativa para automatizar processos relacionados ao recrutamento e seleção.

A aplicação utiliza uma IA capaz de interpretar comandos enviados através de prompts e atuar como um profissional de RH, realizando tarefas como agendamento de entrevistas, comunicação com candidatos e atualização de informações administrativas.

Para permitir a interação entre a Inteligência Artificial e serviços externos, o projeto utiliza o **MCP (Model Context Protocol)**, possibilitando que a IA acesse e utilize ferramentas integradas de forma estruturada e automatizada.

## 🤖 Inteligência Artificial e Integrações

O projeto utiliza uma arquitetura integrada envolvendo diferentes tecnologias:

* API da OpenAI para interpretação dos prompts e processamento das solicitações.
* Hugging Face para integração e utilização de recursos de Inteligência Artificial.
* MCP (Model Context Protocol) para comunicação entre a IA e ferramentas externas.
* Google Cloud para gerenciamento das integrações com serviços Google.

Com essas integrações, a IA consegue executar ações automaticamente em ferramentas como:

* Google Agenda.
* Google Meet.
* Gmail.
* Google Planilhas.

## 🚀 Funcionalidades

* Interpretação de comandos utilizando Inteligência Artificial Generativa.
* Simulação de um assistente virtual de Recursos Humanos.
* Agendamento automático de entrevistas.
* Criação de eventos no Google Agenda.
* Geração de links de reuniões no Google Meet.
* Envio automático de e-mails para candidatos.
* Atualização de informações em planilhas.
* Automação de etapas do processo seletivo.

## ⚙️ Funcionamento

1. O usuário fornece um prompt contendo informações sobre a entrevista, candidato e processo seletivo.
2. A Inteligência Artificial interpreta a solicitação e identifica as ações necessárias.
3. O MCP realiza a comunicação entre a IA e as ferramentas externas configuradas.
4. O sistema cria um evento no Google Agenda com as informações da entrevista.
5. Uma reunião no Google Meet é preparada automaticamente.
6. Um e-mail é enviado ao candidato contendo os detalhes da entrevista e o link da reunião.
7. As informações do processo são registradas e atualizadas em uma planilha do Google.

## 🎯 Objetivo

Este projeto possui finalidade acadêmica e tem como objetivo aplicar conceitos de Inteligência Artificial Generativa, integração de APIs e automação de processos, demonstrando como uma IA pode interpretar solicitações humanas e executar tarefas administrativas de forma autônoma.

A solução apresenta uma aplicação prática da Inteligência Artificial no setor de Recursos Humanos, utilizando MCP como camada de integração entre o modelo de IA e ferramentas externas, permitindo automatizar atividades como agendamento de entrevistas, comunicação com candidatos e organização de informações.
